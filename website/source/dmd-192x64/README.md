# 192x64 display artwork

- `dmd-192x64-cutout.png`: photo of the 192x64 board with its LED grid (192 x 64 LEDs, first LED
  centre at about x 133, y 133.5, pitch about 11.45 px).
- `ppuc-dmd-192x64.jpg`, `zedmd-192x64.jpg`: the cutout with `../../theme/assets/dmd/ppucdmd-192x64.raw`
  and `zedmd-192x64.raw` lit on the LEDs, on the same backdrops as the 128x32 product photos.
  These are the product photos used on janspinballmods.com.

This folder is not part of the built site.
