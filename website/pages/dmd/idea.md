# How PPUC/DMD came to be

PPUC/DMD started as part of [PPUC](../../docs/), the open-source Pinball Power-Up Controller project.
Within PPUC, ZeDMD was created to emulate a real DMD for virtual pinball machines. To use it as a
replacement in real machines, the concept was extended with hardware that reads the original DMD
signal and applies Serum colorizations to it. That solution is PPUC/DMD.
